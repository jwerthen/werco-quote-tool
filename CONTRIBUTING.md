# Contributing

Thank you for contributing to QuoteEngine.

## Development Basics

- Use clear, descriptive commit messages.
- Keep changes scoped to the task you are addressing.
- Add or update tests when you introduce new behavior.

## Code Quality

- Format and lint code before opening a PR.
- Prefer small, reviewable changes over large refactors.

## Documentation

- Update `docs/` when you introduce or change behavior that impacts users or operators.
