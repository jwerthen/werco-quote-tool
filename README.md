# QuoteEngine

QuoteEngine is a manufacturing quote automation tool for metal fabrication shops. This repository is the implementation workspace for the product specification in `overview.md`.

## Repository Structure

- `backend/`: FastAPI backend service and processing engines.
- `frontend/`: React web application.
- `infra/`: Infrastructure and deployment assets (Docker, Kubernetes, Terraform).
- `docs/`: Architecture, API references, and user guides.
- `scripts/`: Utility scripts for local development and maintenance.
